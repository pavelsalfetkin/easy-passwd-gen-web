# Генератор паролей

Веб-приложение и устанавливаемая PWA с REST API. Пароли создаются криптостойко (`crypto.randomInt` на сервере, `crypto.getRandomValues` в браузере) и нигде не сохраняются.

## Требования

- Node.js 18.11 или новее
- Одна зависимость — `express@4`

## Запуск

```bash
npm install
npm start        # http://localhost:3000
npm run dev      # то же с перезапуском при изменениях
npm test         # node:test, без внешних фреймворков
npm run icons    # пересобрать PNG-иконки PWA
```

Переменные окружения: `PORT` (по умолчанию `3000`), `HOST` (`0.0.0.0`), `RATE_LIMIT` (запросов в минуту с одного IP, по умолчанию `120`), `TRUST_PROXY=1` — если сервер стоит за обратным прокси.

HTTPS без внешнего веб-сервера: `TLS_CERT` и `TLS_KEY` — пути к сертификату и ключу (при их наличии сервер сам поднимает HTTPS и включает HSTS), `HTTP_PORT` — необязательный порт для редиректа `http → https` (например, `80`).

## Что умеет интерфейс

- **Обычный режим** — 4 пароля по 8 символов: буквы, цифры и спецсимволы.
- **Кастомный режим** — длина 4–16 (4, 6, 8, 10, 12, 14, 16) и любые комбинации букв, цифр и символов.
- Каждый пароль гарантированно содержит хотя бы один символ каждой включённой категории.
- Копирование пароля и всех паролей, кнопка «Создать ещё».
- Генерация выполняется на устройстве, поэтому работает без сети.

## REST API

База: `/api/v1`. Авторизация не требуется, тела и секреты не сохраняются, ответы генерации идут с `Cache-Control: no-store`.

```bash
# Для AI-агента: GET без тела
curl "http://localhost:3000/api/v1/passwords?length=16&count=4"

# Канонический POST
curl -X POST "http://localhost:3000/api/v1/passwords" \
  -H "Content-Type: application/json" \
  -d '{"length":16,"letters":true,"digits":true,"symbols":false,"count":4}'
```

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/v1/passwords` | Генерация по query-параметрам |
| POST | `/api/v1/passwords` | Генерация по JSON-телу |
| GET | `/api/v1/options` | Дефолты, лимиты, категории символов |
| GET | `/api/v1/health` | Статус сервиса |
| GET | `/api/v1` | Карта API и пример запроса |
| GET | `/openapi.json` | Спецификация OpenAPI 3.1 |
| GET | `/docs` | Человекочитаемая документация из спеки |

Параметры: `length` (4–64, по умолчанию 8), `letters`, `digits`, `symbols` (true/false, по умолчанию true), `count` (1–10, по умолчанию 4). Неизвестные параметры отклоняются с `400` — так агент сразу видит опечатку.

Ошибки приходят в формате `application/problem+json` с массивом `errors`:

```json
{
  "title": "Некорректные параметры",
  "status": 400,
  "errors": [{ "field": "length", "message": "Длина должна быть от 4 до 64" }]
}
```

Ограничения: тело запроса до 16 КБ, лимит `120` запросов в минуту с IP (`429` + `Retry-After`).

## Установка на телефон (PWA)

- **Android / Chrome**: откройте сайт, нажмите «Установить приложение» или меню → «Установить приложение».
- **iOS / Safari**: «Поделиться» → «На экран „Домой“».

Важно: service worker и установка PWA работают только в secure context — на `localhost` или по HTTPS. При открытии по `http://192.168.x.x:3000` приложение работает, но кнопка установки не появится. Для проверки на телефоне используйте HTTPS-туннель (например, reverse proxy с сертификатом) либо проброс порта на `localhost`.

## Структура

```
server.js              запуск Express и graceful shutdown
src/app.js             маршруты API, статика, security headers, обработка ошибок
src/problem.js         ответы в формате problem+json
src/rate-limit.js      лимитер по IP в памяти процесса
src/rng-node.js        crypto.randomInt для сервера
shared/generator.js    изоморфный генератор и лимиты
shared/options.js      изоморфная валидация параметров
public/                UI, стили, service worker, manifest, иконки, /docs
openapi.json           контракт API (OpenAPI 3.1)
tests/                 node:test для генератора и API
scripts/               генерация PNG-иконок на встроенном zlib
```

## Безопасность и ограничения

- Пароли не логируются, не кешируются и не хранятся; истории паролей нет.
- UI не отправляет пароли на сервер — генерация локальная. API предназначен для агентов и интеграций.
- CSP запрещает inline-скрипты и стили, внешние CDN не используются.
- Лимитер хранится в памяти процесса: при нескольких инстансах нужен общий стор.
