# Project Documentation Rules (Non-Obvious Only)

- Проект больше не Telegram-бот: `index.js`, `node-telegram-bot-api`, `settings.js` и опечатка `lenght` удалены. Упоминания бота в старых коммитах и заметках не относятся к текущему коду.
- Точка входа — `server.js`, а вся маршрутизация и middleware — в `src/app.js`; `package.json` содержит `"type": "module"`.
- Каталог `shared/` раздаётся статикой по `/shared`, поэтому секреты и серверную логику туда класть нельзя.
- Страница `/docs` не хранит текст документации: она рендерит `openapi.json` в браузере, поэтому правка спеки сразу меняет документацию.
- Сборщика нет: браузер загружает нативные ES-модули, поэтому открыть `public/index.html` через `file://` нельзя — нужен запущенный сервер.
- Имя пакета `easy-passwd-gen-web` не совпадает с каталогом `easy-passwd-gen-web-sc`; это не веб-версия бота, а самостоятельное приложение с REST API.
- PNG-иконки в `public/icons` — сгенерированные артефакты (`npm run icons`), а не дизайн-исходники.
